# ROC-RK3568-PC OpenBMC

> OpenBMC 固件项目，为 Firefly ROC-RK3568-PC 开发板打造

## 硬件平台

- **SoC**: Rockchip RK3568
- **CPU**: 四核 Cortex-A55 @ 2.0GHz
- **内存**: 2GB/4GB/8GB LPDDR4

## 功能特性

- 🌐 Web 管理界面
- 🔌 IPMI 2.0
- 📡 Redfish API
- 🔐 SSH 访问

## 快速开始

### GitHub Actions

1. Fork 本仓库
2. 访问 Actions 标签
3. 运行 Build OpenBMC 工作流
